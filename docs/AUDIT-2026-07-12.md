## 2. Logical errors (real bugs)

1. **PWA "Mark as Settled" is broken.** `printit-web-app-for_end_user/pages/owner/settlements.tsx:106`
   POSTs to `/owner/settlements` — that route does not exist on the backend.
   The correct route is `POST /owner/settlements/manual` (the admin dashboard's
   `admin-settlements.html:660` uses it correctly). Every click returns 404.

2. **Payment-config proof images never load.** `printit-admin-dashboard/admin-payment-config.html:182`
   builds `API_BASE + '/storage/<path>'`, but the backend mounts no static
   `/storage` route and Caddy proxies everything to the API — so these URLs 404.
   The `onerror="this.style.display='none'"` hides the failure silently, so
   admins approve payment-config requests without ever seeing the proof. Fix:
   serve proofs through an authenticated proxy route (pattern already exists:
   `GET /owner/kyc-doc?path=...` in `owner.py:63`).

3. **Doc contradictions.**
   - Root `CLAUDE.md` says the backend deploys to **Fly.io (`bom`)**; the backend's
     own `CLAUDE.md` + `docs/DEPLOYMENT.md` say **OVH VPS via Docker Compose**.
   - Backend `CLAUDE.md` says "Uvicorn (2 workers in prod)" in Stack but
     "**one worker on purpose**" (ws_manager is per-process) in Deploy. The
     1-worker statement matches `deploy/docker-compose.yml`.

4. **Android versionCode ambiguity.** Both TWA copies and the built artifacts are
   `appVersionCode 1` / `appVersion "1"`. Bump in `android-twa/twa-manifest.json`
   before the next Play upload or the bundle will be rejected as a duplicate.

## 4. Ambiguities / structure notes (working, but confusing)

1. **"owner" ≠ owner.** Backend `owner.py` routes (`/owner/*`) are **platform-admin**
   endpoints (well-documented in `get_owner_user`), while kiosk owners use
   `kiosk.py` (`/kiosk/*`). Confusing naming, correct behaviour — don't "fix"
   without reading the IDOR warning in `owner.py:44`.
2. **Admin dashboard file naming:** `admin-*.html` = platform-admin pages (hidden
   nav section), plain names = kiosk-owner pages. `payment-config.html` (owner
   setup) vs `admin-payment-config.html` (admin request review) is the worst pair.
3. **Pi endpoints split across routers:** `/printers/pi/register` +
   `/printers/pi/{id}/heartbeat` live in `printers.py`; everything else Pi-related
   is `/pi/*` in `pi.py`. The agent calls both families.
4. **Paper-shop listing lives in `jobs.py`** (`GET /jobs/paper-shop`) while its
   admin CRUD is in `admin.py` (`/admin/paper-shop`).
5. **No version control:** `printit-refiller-app/` and `printit-landing/` have no
   `.git` (refiller even has a `.gitignore` but no repo). Everything else is a
   nested repo.
6. **Refiller app authenticates as kiosk owner** (`/kiosk/me`, `/kiosk/printers`)
   — there is no separate refiller role; a "refiller" is a kiosk-owner account.
